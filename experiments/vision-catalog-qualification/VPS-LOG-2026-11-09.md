**diagnosis and verification of a fix**, not for another attempt at the same code.

## Host requirement

Prior arms ran on an **AMD EPYC 7R13 (Zen 3, AVX2, `active-vector-bits = 256`)**. Reduction order
in the kernels depends on vector width and thread count, so a wider-vector host would produce
different arithmetic and a result not comparable to the recorded runs. Threads are pinned to 8 by
the manifest. **Verify `active-vector-bits = 256` on the box before trusting any arithmetic
comparison**; if the box reports 512, pin the width or pick another type.
