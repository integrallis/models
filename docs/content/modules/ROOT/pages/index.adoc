= Models
:navtitle: Models

Models is an in-process inference library for Java applications. Inference is
the work of running a trained model to produce an answer. With Models, an
application can load an open-weight language model and generate text without
starting Python, calling a separate model server, or sending prompts over the
network.

Models currently loads language models distributed as GGUF files. GGUF is a
file format used by the local-model ecosystem to package a model's structure,
tokenizer metadata, and trained numeric weights. Those weights are commonly
quantized, which means they are stored with fewer bits so the model needs less
disk space and memory.

Running the file efficiently requires more than parsing it. The runtime must
map large weight tensors into memory, convert text to tokens, execute every
transformer layer, retain the attention history in a key-value (KV) cache, and
select and stream each new token. The most expensive steps are numeric kernels
limited by memory bandwidth and SIMD throughput. Models implements that
complete pipeline in Java 25 and uses the Vector API to reach the CPU's SIMD
instructions.

`backend-java` executes every inference kernel in Java. `backend-native` runs
the same Java pipeline but replaces selected, measured bottleneck kernels with
a small Models-owned Rust library through Java's Foreign Function and Memory
(FFM) API. It does not embed or invoke llama.cpp or Ollama.

== Published Modules

[cols="1,3",options="header"]
|===
|Artifact |Purpose

|`models`
|Application-facing API and generation-runtime facade

|`models-api`
|Backend, tokenization, sampling, streaming, metadata, and diagnostics contracts

|`models-runtime`
|Generation loop, prompt-prefix reuse, sampling, and streaming

|`backend-java`
|GGUF model loading and Java 25 Vector API execution

|`backend-native`
|The Java backend with selective Rust/FFM bottleneck-kernel substitution

|`models-rag`
|Framework-neutral grounding, citation, abstention, and extractive-fallback policy

|`models-semantic-order`
|Pure-Java WordTour semantic-order models

|`models-langchain4j`
|LangChain4j `ChatModel` adapter

|`models-spring-ai`
|Spring AI blocking and streaming chat adapters

|`models-embedding`
|Optional Models-to-Vectors storage and semantic-cache bridge
|===
