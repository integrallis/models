= Guarded RAG
:navtitle: Guarded RAG

Small local models need an explicit policy for weak retrieval, unsafe retrieved
text, unsupported claims, and source attribution. `models-rag` validates the
retrieved context before generation and validates the answer afterward without
coupling the application to a framework.

== Before Generation

Retrieved documents are untrusted input. Call `assess` before placing them in a
prompt:

[source,java]
----
GroundingContextDecision context = policy.assess(question, evidence);
if (!context.generationAllowed()) {
    return GroundedAnswerPolicy.ABSTENTION;
}

String rawModelText = model.generate(prompt);
GroundedAnswer answer = policy.apply(question, evidence, rawModelText);
----

The preflight rejects empty or low-confidence retrieval, evidence unrelated to
named entities in the question, more than 32 documents, more than 131,072
characters, common instruction-override phrases, and model control-token
delimiters. Use `GroundingLimits` to choose lower context and fallback limits
for a model with a smaller context window.

== Decisions

`GroundedAnswerPolicy` produces one of five outcomes:

* `MODEL_ANSWER` for supported text with trusted citations
* `MODEL_ANSWER_WITH_DERIVED_CITATIONS` for supported text that omitted citations
* `MODEL_ABSTENTION` when the model explicitly reports insufficient context
* `RETRIEVAL_ABSTENTION` when retrieval does not clear the configured gate
* `EXTRACTIVE_FALLBACK` when generated claims cannot be grounded

The result keeps both the raw model output and the final application answer.

== Apply the Policy

[source,java]
----
var evidence = List.of(
    new GroundingDocument(
        "policy-17",
        "Cancellation policy",
        "Orders can be cancelled without charge before shipment.",
        4.2f,
        1));

var policy = GroundedAnswerPolicy.productionDefault();
if (!policy.assess("When can an order be cancelled?", evidence).generationAllowed()) {
    return GroundedAnswerPolicy.ABSTENTION;
}
GroundedAnswer answer = policy.apply(
    "When can an order be cancelled?",
    evidence,
    "Orders can be cancelled without charge before shipment. [policy-17]");

System.out.println(answer.decision());
System.out.println(answer.text());
----

The retrieval score is application-specific. Set an explicit threshold when
the retriever's score scale differs from the production default:

[source,java]
----
var policy = new GroundedAnswerPolicy(0.78f);
----

Custom limits are explicit:

[source,java]
----
var limits = new GroundingLimits(
    12,      // maximum retrieved documents
    48_000,  // maximum retrieved characters
    2,       // maximum fallback documents
    2_000);  // maximum fallback characters
var policy = new GroundedAnswerPolicy(0.78f, limits);
----

== Qualification

The controlled RAG suite gives plain Java, LangChain4j, Spring AI, Ollama,
llama.cpp, and hosted providers the same corpus, retrieval results, prompt,
sampling controls, and correctness rules. Results include TTFT, decode
throughput, end-to-end latency, grounding decisions, and answer correctness.
