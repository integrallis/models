# SQLCoder Q5_K fused-reduction diagnostic

This directory preserves the controlled retention gate for the x86-64 AVX2 Q5_K fused integer
reduction. It is diagnostic optimization evidence, not a launch qualification.

Both runs used the exact 4,783,256,288-byte SQLCoder-7B-2 Q5_K_M artifact with SHA-256
`0068f25d1fc37cb25aa6be85064432eeeb1a0754d97139c0d2eb3529fc8fc32b`, the `SQL:` prompt,
two warmups, ten measured trials, four generated tokens, greedy sampling, four active processors
and Rust workers, GraalVM Community Java 25.0.3, and the controlled AMD EPYC-Milan host.

| Metric | Per-group horizontal reduction | Fused AVX2 lane reduction | Change |
| --- | ---: | ---: | ---: |
| p50 TTFT | 3,959.5 ms | 2,366.8 ms | -40.2% |
| p95 TTFT | 4,145.4 ms | 2,498.4 ms | -39.7% |
| p50 prefill | 4.91 tok/s | 8.41 tok/s | +71.1% |
| p50 decode | 0.946 tok/s | 0.938 tok/s | -0.9% |
| p95 TPOT | 1,063.5 ms | 1,079.5 ms | +1.5% |

All twenty trials succeeded. Every corresponding output has SHA-256
`b828ee954291cba36252f48c256a3f64e509979c20e551ddd7af2ea97c178d33`, so the retained
prefill improvement does not change generated bytes. Decode is effectively unchanged and remains
`OFFLINE`; the fused kernel does not qualify SQLCoder for production use.
