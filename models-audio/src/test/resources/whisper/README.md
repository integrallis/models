# Whisper frontend oracle fixtures

`window-400.f32` and `mel-filterbank-80x201.f32` are **extracted verbatim from a published
artifact**, not generated by this repository:

    handy-computer/whisper-tiny-gguf / whisper-tiny-Q5_K_M.gguf
    tensors `frontend.window` (400 F32) and `frontend.mel_filterbank` (dims [201, 80], F32)

That converter ships the analysis window and the mel filterbank as tensors inside the model, which
makes them an oracle for `WhisperMelFrontend` rather than a fixture we wrote to match our own
output. Little-endian float32, and the filterbank is mel-major with the 201 bins contiguous, which
is what GGUF's fastest-varying-first dimension order means for `dims [201, 80]`.

Regenerate by reading those two tensors out of that artifact. Do not hand-edit: the point of these
files is that nothing in this repository produced them.
